1. 层间如何连接：上一层的第二次 Add 输出，直接进入下一层

u[i] = h[i] + Mixer[i](InputNorm[i](h[i]), state[i])
h[i+1] = u[i] + MoE[i](PostNorm[i](u[i]))

每层有 两次残差相加：R1 绕过 InputNorm 和注意力，R2 绕过 PostNorm 和 MoE。层与层之间没有额外的第三次 Add；h[i+1] 同时是下一层的主路输入和下一层 R1 的起点。每层状态只反馈给下一时间步的同一层，不传给下一层。
